# agent-hotwash

Analyze coding-agent traces for execution patterns and evidence-linked guidance
improvements.

## Start here

```bash
uvx agent-hotwash analyze /path/to/traces --semantic off --format html --out report.html
```

See the [README](https://github.com/svilupp/agent-hotwash#readme) for installation,
CLI options, configuration, and development commands.
